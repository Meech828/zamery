# Калькулятор замеров

Личный калькулятор замеров тела: вес и объёмы, красивый дашборд прогресса, который можно скачать картинкой или отправить в мессенджер.

- Сначала нужно выбрать пол (женщина или мужчина), потом отметить нужные параметры и день недели для замеров.
- Данные хранятся **только в браузере на устройстве пользователя**. На сервер ничего не отправляется.
- К каждому замеру можно прикрепить фото (спереди, сбоку, сзади) и сравнивать «было и стало».
- Резервная копия (.json, вместе с фото) и выгрузка таблицы в CSV для Excel или Google Таблиц.

Чтобы открыть калькулятор, перейдите по ссылке GitHub Pages этого репозитория или скачайте `index.html` и откройте его в браузере.
